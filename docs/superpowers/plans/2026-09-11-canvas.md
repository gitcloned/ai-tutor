# Canvas implementation plan

Approved design: shared ivory notebook, left drawing tools, bottom-right tutor orb; React and tldraw in canvas/. Backend remains owner of event ordering and transformation. Replay scripts/canvas.mjs is the integration fixture.

- [ ] Create the standalone Vite app and event adapter. Test write sentinels, Unicode narration, safe media, position anchors, and serial/cancellable presentation.
- [ ] Build tldraw renderer: independent text blocks, sanitized SVG assets, video embeds, question focus, automatic placement, and gentle camera following that yields to student activity.
- [ ] Build the approved UI: toolbar, responsive header, connect sheet, notebook, transcript, and accessible orb with distinct tap/hold behavior. Support local canvas persistence. Explain unavailable image submission honestly.
- [ ] Integrate WebSocket playback with ordered audio/visual presentation, pause/resume, errors and explicit reconnection. Simulated narration remains captions, not fake speech.
- [ ] Run production build and tests. Launch the actual replay on a separate port and verify algebra and heart rendering, drawing, persistence, and mobile layout in a browser. Document startup and limitations.

Palette: paper #fbfaf6, ink #243d33, fern #416653, pencil blue #356aca, muted #7e877e. Georgia wordmark and system UI chrome; tldraw handwritten equations. The canvas and orb carry the identity. No chat feed or metrics dashboard.
