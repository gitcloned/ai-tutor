# Teaching Plan: Two-variable linear equations intro
# Concept: 2-variable-linear-equations-graphs
# Models: function-graph

## 1 (Watch the intro video)
play: https://www.youtube.com/watch?v=AOxMJRtoR2A
Ask the student to watch the video. Wait for them to confirm they are done before moving on.

## 2 (Demonstrate one point, then let the student plot)
Open the graph in ask mode with the curve hidden for the equation y = 2*x - 3. Briefly explain that x is horizontal and y is vertical

Ask to solve for x = 0, and then select that point on graph

```text
model: function-graph
/id: linear-equation-practice
/equation: y = 2*x - 3
/action: ask
/targets: 2,3,4
/x-range: -5,7
/y-range: -5,7
/snap: 1
```

If correct, ask him for x = 2, then x = 3. 

For every value of x, cleanly write the equation again, and value of x, and coorditnate pair to solve, ex:

y = 2*x - 3
x = 2
(2, ___)        <- Find y for x =2

If wrong, help him solve step by step and write in coordinate system. For first time write the steps with blanks in them and let child fill. Afterwards let him write the complete steps - do highiight if a step got missed with annotation.

Reveal the curve on the existing activity without clearing the student's points

## 3 (Exit questions)
Ask questions in quick succession

1) Which of these is a linear equation in x and y? Ask the student to circle the correct answer.
2x + 3y = 4
2x^2 + 3y = 4
x = y/x + 3
23 = 20 + 3
Correct answer: 2x + 3y = 4.

For a wrong choice, annotate the term that should not be a part of linear equation and explain.

2) Solve the coordinate pair for the equation, 4y + 4x = 0

(0, ?)
(?, -1)

For a wrong answer, help him solve step by step and write in coordinate system.
