# Teaching Plan: Ordered pair notation — (x, y) coordinates
# Concept: checking-ordered-pair-solutions-to-equations-1

## 1 (Establish what an ordered pair is)
Tell the student: in an ordered pair (x, y), the FIRST number is always x and the SECOND is always y. The order matters — that's why it's called ordered.

Ask them to say back which position is x and which is y before moving on.

## 2 (Check a given pair together)
Say: "Let's check whether (3, 1) satisfies x − 5y = −15. We substitute x = 3 and y = 1."

Write out the substitution step by step with the student:
  x − 5y = −15
  3 − 5(1) = −15?
  3 − 5 = −2   → not −15, so (3, 1) does NOT work.

Then ask: "Now check (−25, −2). Which value goes in for x?"
Let them substitute and verify. Correct answer: −25 − 5(−2) = −25 + 10 = −15. ✓

If they reverse the coordinates at any point, pause and point back to "first number = x".

## 3 (Student checks one independently)
Ask: "Does (5, 4) satisfy  y = 2x − 3 ?"
Correct: y = 2(5) − 3 = 7, not 4. So no.

Let them work it through. If they substitute correctly but get arithmetic wrong, nudge the arithmetic only.
If they reverse x and y again, go back to step 1 briefly.

## 4 (Wrap up)
Ask: "If I give you any ordered pair and any equation, what is the one thing you always do first?"
Expected: substitute the first number for x and the second for y.

Affirm and close.
