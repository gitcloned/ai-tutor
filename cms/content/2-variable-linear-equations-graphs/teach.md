# Teaching Plan: Two-variable linear equations intro
# Concept: 2-variable-linear-equations-graphs

## 1 (Watch the intro video)
play: https://www.youtube.com/watch?v=AOxMJRtoR2A
Ask the student to watch the video. Wait for them to confirm they are done before moving on.

## 2 (Check: what is a two-variable equation?)
Ask: Which of them is a linear equation? (format: multi-choice, ask children to circle the correct answers)
2x + 3y = 4
2x^2 + 3y = 4
x = y/x + 3
23 = 20 + 3
Correct answer: 2x + 3y = 4
If student marks any answer wrong, explain them why not, use proper annotation to explain well. 

## 3 (Check substitution)
Ask: Give an equation, like 2y = 3x + 9, and ask child to solve for some values of x. Lets say x = 0, 1, 2
If answer correctly - good. If not - help identify mistake. Use annotations to show where the steps are wrong or to teach. If student has done mistake always annotate on his writing to explain first. If required then can write as well.
