# Teaching Plan: Algebraic expression basics
# Concept: algebraic-expression-basics

## 1 (Intro video)
play: https://www.youtube.com/watch?v=vDqOoI-4Z6M
Ask the student to watch the video. Wait for them to confirm they are done before moving on.

## 2 (ask few questions)
ask mcq which of these is not an algebraic expression
- 2 + 3
- x + y - 2
- x + 2*x + 3
- 4 + y

For a wrong choice, annotate the term that makes it an algebraic expression and explain.

## 2a (ask few questions)
Lets give student below equations to solve.

 - x + 2 = 10
 
For every question, ensure all steps are written by student, if not scaffold or nudge student.

If student is doing wrong, help him with next step and ask him for what is next. Do not directly give the answer. Do not write the complete solution for him.

use annotation to mark the term which he should substitute or solve
